# ناقل — أداة تنزيل الفيديوهات (Flask + yt-dlp)

تطبيق ويب لتنزيل فيديوهات من يوتيوب / تيك توك / فيسبوك بجودات مختلفة،
مع صفحة مستخدمين وصفحة إدارة (أدمن) لمتابعة الإحصائيات، مصمم للعمل داخل **Termux**.

## 1. تجهيز Termux

```bash
pkg update && pkg upgrade -y
pkg install python ffmpeg git -y
```

`ffmpeg` ضروري لدمج الفيديو والصوت واستخراج MP3.

## 2. تثبيت المتطلبات

انسخ مجلد المشروع إلى جهازك، ثم:

```bash
cd video_downloader
pip install -r requirements.txt
```

## 3. ضبط بيانات الأدمن (مهم قبل النشر)

عدّل هذه المتغيرات قبل التشغيل الفعلي (لا تتركها كما هي):

```bash
export ADMIN_USERNAME="اسمك_الخاص"
export ADMIN_PASSWORD="كلمة_مرور_قوية"
export APP_SECRET_KEY="نص_عشوائي_طويل"
```

## 4. التشغيل

```bash
python app.py
```

سيعمل الخادم على المنفذ 5000. افتح من متصفح الجهاز نفسه:

```
http://127.0.0.1:5000
```

### للوصول من جهاز آخر على نفس الشبكة
استخدم عنوان IP الخاص بجهازك بدل 127.0.0.1، مثال:
```
http://192.168.1.10:5000
```

### للوصول من الإنترنت (اختياري)
يمكنك استخدام أداة مثل `cloudflared` أو `ngrok` داخل Termux لعمل نفق (tunnel) للمنفذ 5000
حتى تحصل على رابط عام يمكن مشاركته.

## 5. الدخول للوحة تحكم الأدمن

افتح:
```
http://127.0.0.1:5000/admin
```
وسجّل الدخول ببيانات `ADMIN_USERNAME` و `ADMIN_PASSWORD` التي ضبطتها.

## هيكل المشروع

```
video_downloader/
├── app.py                  # الخادم (Flask + yt-dlp)
├── requirements.txt
├── app.db                  # قاعدة بيانات SQLite (تُنشأ تلقائيًا)
├── downloads/               # الملفات المُنزّلة (تُنشأ تلقائيًا)
├── templates/
│   ├── index.html           # صفحة المستخدم
│   ├── admin_login.html     # تسجيل دخول الأدمن
│   └── admin_dashboard.html # لوحة تحكم الأدمن
└── static/
    ├── style.css
    └── app.js
```

## ملاحظات مهمة

- **الخصوصية**: التطبيق يسجّل اسم المستخدم (إن أدخله) وعنوان IP وسجل التنزيلات في قاعدة بيانات محلية (`app.db`) ليراها الأدمن فقط.
- **الحقوق**: استخدم الأداة لتنزيل المحتوى الذي تملك حقوقه أو المسموح بتنزيله فقط، واحترم شروط استخدام كل منصة (يوتيوب/تيك توك/فيسبوك) وحقوق صانعي المحتوى.
- **yt-dlp قد يحتاج تحديثًا دوريًا** لأن المنصات تُغيّر بنيتها باستمرار:
  ```bash
  pip install -U yt-dlp
  ```
- بعض فيديوهات فيسبوك الخاصة/المحمية بخصوصية معينة قد لا يمكن جلبها لأن المنصة تمنع الوصول لها دون تسجيل دخول.
